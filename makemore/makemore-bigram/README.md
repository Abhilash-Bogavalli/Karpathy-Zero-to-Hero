# makemore-bigram

Character-level language models following Karpathy's makemore series.

## Contents

- `makemore.ipynb` — bigram and count-based models from scratch
- `names.txt` — training data: 32k human names
- `cities.txt` — training data: city names
- `makemore-mlp/` — MLP-based variant (see its own README)

## What This Is

Starting from the simplest possible language model (bigram character counts), building up intuition for how neural networks learn to generate text.
