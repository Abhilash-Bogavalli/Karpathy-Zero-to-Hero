# ml-learning

My personal machine learning learning log — notebooks, experiments, and notes as I work through foundational ML material.

## Structure

```
ml-learning/
├── karpathy-zero-to-hero/     # Andrej Karpathy's Zero to Hero series
│   ├── micrograd/             # Autograd engine from scratch
│   └── makemore/              # Character-level language models
│       └── makemore-mlp/      # MLP variant (Bengio et al. 2003)
├── strang-linear-algebra/     # Gilbert Strang's Linear Algebra course
│   ├── week1-vectors/
│   └── week2-matrices/
└── other/
    └── intro-to-fastapi/      # First steps with FastAPI
```

## About

**Karpathy — Zero to Hero**: Working through [Andrej Karpathy's neural network series](https://www.youtube.com/playlist?list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ) from first principles. Covers backprop, autograd, and language models.

**Strang — Linear Algebra**: Notes and exercises from Gilbert Strang's MIT 18.06 course. In progress.

**Other**: Standalone explorations that don't fit a larger series.
