# micrograd

My implementation of [micrograd](https://github.com/karpathy/micrograd) following Karpathy's Zero to Hero series.

## What This Is

A scalar-valued autograd engine built from scratch — no PyTorch, no NumPy autograd. Implements forward and backward passes manually, then builds a small neural network on top of it.

- `micrograd.ipynb` — notebook with the full implementation and walkthrough
